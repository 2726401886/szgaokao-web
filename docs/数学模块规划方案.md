# 科科通 · 数学学科模块规划方案（v1）

> 平台：szgaokao.toolshe.cn（科科通 · 多学科题库）｜规划人：创始人｜状态：待确认
> 定位：在现有「小学 / 中考 / 高考英语」三模块基础上，新增**数学学科**，覆盖小学—初中—高中，复用现有授权、题库、学习、报告全链路。

---

## 一、模块定位与授权接入

| 项 | 规划 |
|---|---|
| 模块标识 | `math`（可细分 `math_p` 小学 / `math_m` 初中 / `math_h` 高中，见下） |
| 授权体系 | `MODULES` 增加 `math:'数学'`；按模块授权机制已支持（admin「调整授权」勾选 modules 数组），新增后即可独立售卖 |
| 体验模式 | 沿用 TRIAL 机制：未授权只放行第一个单元 + `trial:true` + 管理员微信横幅 |
| 导航 | 主页 index.html 增加「数学」模块卡片；小学/中考/高考数学三入口按钮 |
| 与英语差异 | 数学无听力音频，答题全部客观判分（选择/填空/判断），**上云记录天然适配**（本次中考答题记录方案可直接复用） |

## 二、题库结构（沿用现有 JSON 模式）

### 2.1 小学（1-6 年级，对标人教/北师大/苏教版）

```
data/math_primary.json
volumes[]:
  id: mp1 ~ mp6（年级）
  title: 一年级上册…
  units[]: 单元（如 20以内加减法）
    topics[]: 知识点
      items[]:
        { id: mp1-u1-t1-q1, type: choice|fill|judge, q, options?, answer, tip, grade }
```

- 每单元 8-12 题，选择 + 填空 + 判断混合
- 按「知识点」聚合，适配单题视图 + 题号导航（复用 quiz.html 交互）

### 2.2 初中（7-9 年级，对标新课标）

```
data/math_middle.json
volumes[]: 按年级/册 → 单元 → 知识点 → 题
```

- 覆盖：实数、代数式、方程与不等式、函数（一次/二次/反比例）、几何（三角形/四边形/圆）、统计概率
- 每题带 `tip`（考点）与 `analysis`（解析），填空题自动判分（严格匹配 + 容错别名）

### 2.3 高中（必修+选修，对标新高考）

```
data/math_high.json
volumes[]: 必修一~五 / 选必一~三 → 单元 → 知识点 → 题
```

- 覆盖：函数与导数、三角函数、数列、立体几何、解析几何、概率统计、不等式
- 解答题暂以「分步答案 + 考点解析」呈现（主观判分留给后期「拍照批改」）

## 三、页面与功能规划

| 页面 | 功能 | 复用 |
|---|---|---|
| `math.html`（小学/初中/高中三合一，参数切换） | 左侧目录（册→单元→知识点），右侧单题视图 + 题号导航 + 即时判分 + 正确率 | quiz.html 交互 |

- report 拉取合并，按「知识点」展示薄弱项 + 复习建议

## 六、风险与待确认

1. **命名空间**：数学进度命名 `progress.math`，与英语模块互不干扰 ✅
2. **填空题判分**：需建立容错表（如「π」「22/7」「3.14」），首期可只做选择/判断，填空二期开放
3. **授权拆分**：数学是否按「小学数学/初中数学/高中数学」三独立模块售卖？建议**一个 math 模块整体售卖**（降低后台复杂度），需创始人确认
4. **学科扩展**：后续物理/化学按同一模板复制（`MODULES` + `data/*.json` + 页面复用），模板化成本低

---

## 七、结论（待创始人拍板）

- 建议先做 **P1 首发：小学三年级 + 初中实数/方程** 两个单元集上线，验证数学模块转化
- 需确认：① 数学是否单模块售卖 ② 填空题型是否首期开放 ③ 首发范围是否调整

1. 低龄(3–8)赛道高度"游戏化+IP+情境"，客单低(APP 订阅 ¥200–400/年)；
2. 小学高年级→高中转向"校内同步+体系"，客单飙升(直播课 ¥7000–16000/年)；

### B. 同类产品优点提炼（可"取"的 9 条）

1. **情境化/可理解性输入**：洪恩"帮小动物分饼干学平均分"、宝宝巴士生活场景 → 数学题配生活情境图/短文，降抽象门槛（呼应英语模块的"场景化"基因）。
2. **游戏化闭环**：洪恩/悟空"学-玩-练-测"四环节 + 闯关收集 → 单元内做"闯关进度条"，做完给成就。
3. **IP/剧情带动**：洪恩魔法学院、悟空西游 → 轻量"数学小探险"主线（不强制、低成本）。
4. **逻辑思维专项**：悟空"找不同/走迷宫/图形配对/规律填空/镜像对称" → 小学低年级加"图形与逻辑"专项题型（非超前，培养底层能力）。
5. **即时反馈+错题本+学情报告**：都都/斑马/火花 → 复用科科通已有"进度上云+学情报告"链路，强化"错题本/薄弱知识点 Top5"。
6. **AI 自适应难度**：洪恩/斑马按正确率调难度 → 数学模块可按单元正确率动态推题（同现有答题记录方案）。
7. **CPA 教学法(具象→图形→符号)**：伴鱼/新加坡数学 → 低年级概念先具象(实物图)再符号，配图解题。
8. **免费入门+订阅/内购**：宝宝巴士/洪恩 → 沿用科科通 TRIAL 体验机制(首单元免费)即对标"免费入门"。
9. **多感官互动(拖拽/手写/点击)**：洪恩"屏幕写数字" → 低年级可加"拖拽点数""手写数字"互动（需前端投入，建议二期）。

### C. 以小学英语模块为样版 —— 结构映射

**小学英语(primary)模块现状（样板）**：
- 数据：`primary_listening_default` = `{product,version,note, volumes[]{id,grade,title,topic,questions[]{id,type,audio,options,answer,tip}}}`
- 接口：`/api/primary-listening` 等，按 grade/vol 取卷；trial 只放首单元
- 页面：`primary-listening.html` 逐题播放音频+选项点击+即时判分+解析(tip)
- 授权：`modules.primary` 独立售卖 + TRIAL

**数学模块据此映射（小学数学 tier = 主样板）**：
- 数据：`math_primary.json` 同构
  `{product,version,note, volumes[]{id(mp1..mp6),grade,title,semester,topic,questions[]{id,type, q,options?,answer,tip,analysis?,scene?}}}`
  - 新增 type：`scene`(情境应用题，配图)、`logic`(逻辑专项：找规律/图形配对/镜像)
  - 每题加 `analysis` 解析（对标英语 tip，且数学更需讲清"为什么"）
- 接口：`/api/math?level=p` 同模式；`modules.math` 授权；trial 首单元
- 页面：`math.html` 复用 primary-listening 的"逐题视图+即时判分+解析+题型导航"，去音频、改"情境图/草稿区"
- 初中/高中 tier 复用同一模板（无 audio；type 以 choice/judge/fill + 解答 steps）

**新增（取自竞品、低代码即可做）**：单元"闯关进度条"+单元成就(#2)；错题本+薄弱知识点 Top5(#5，复用上云进度)；单元正确率→动态推题(#6)；低年级"情境图+图形逻辑专项"(#1/#4/#7)。

### D. 定位与定价建议（基于调研）

- **竞品痛点**：直播课贵(¥7000–16000/年)；纯游戏 APP"玩得开心但不讲思路"，游戏完成度≠理解深度。
- **本品差异化定位**：**"校内同步 + 高性价比体系化题库 + 即时反馈/学情报告 + 可打印"**——比直播课便宜一个数量级，比纯游戏 APP 更"讲思路/接校内"。
- **定价**：沿用科科通单模块售卖逻辑；数学建议**整体售卖**（呼应 v1 待确认①，也对齐洪恩等"单 App 打包"），对标洪恩 APP 订阅(¥198–398/年)但覆盖更广(小学–高中)，可用"单科/全科"梯度。

### E. 修订后的待确认（含调研建议）

1. 数学是否单模块整体售卖？→ 调研建议：**单 `math` 模块整体售卖**（竞品多为单 App 打包，且降低后台复杂度）。
2. 填空题型首期是否开放？→ 建议：**首期开放 choice+judge，fill 二期**（填空判分需容错表，v1 已标注风险）。
3. 首发范围？→ 建议：**小学数学三年级上册(试水低龄情境/闯关) + 初中一年级实数/方程(获客刚需)**，与 v1 P1 一致，验证后扩。
4. 新增待确认：是否做"低年级图形/逻辑专项"与"情境图"？(取自悟空/洪恩优点，需配图投入，建议二期)
